# suckless

my personal builds of suckless tools for Arch.

## tools

- **dwm** — window manager
- **dmenu** — dynamic menu
- **st** — simple terminal
- **slstatus** — status bar (full)
- **slstatus-mini** — status bar (minimal)

## install

```bash
git clone https://github.com/eldiegoveliz/suckless ~/.config/suckless
cd ~/.config/suckless/<tool>
sudo make clean install
```
